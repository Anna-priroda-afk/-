# Подключение заявок к Google Таблице

1. Откройте [таблицу](https://docs.google.com/spreadsheets/d/1Nj8GuJzeDfqNMu0rTpebgVF0tLohYgfkIwt_T3hrSUo/edit) → **Расширения → Apps Script**.
2. Удалите код в `Code.gs` и вставьте содержимое файла `google-apps-script.gs`. Сохраните (`Ctrl+S`).
3. **Развернуть → Новое развёртывание → Веб-приложение**:
   - Тип доступа: **Все**;
   - Выполнять как: **Я**;
   - нажмите «Развернуть» и разрешите доступ.
4. Скопируйте адрес развёрнутого приложения вида  
   `https://script.google.com/macros/s/AKfycb.../exec`.
5. В файле `script.js` уже вставлен рабочий адрес веб-приложения. Если вы переразвернёте скрипт и получите новый URL, замените значение `LEAD_ENDPOINT`.

**Важно после любого изменения кода скрипта:** просто сохранить `Ctrl+S` недостаточно — нужно **Развернуть → Управление развёртываниями → выбранная версия → Изменить → Развернуть** (или создать новое развёртывание). Иначе сайт продолжит использовать старую версию.

Телефон записывается как текст: колонка «Телефон» получает формат `@`, а номер отправляется без плюса — `+7 (999) ...` превращается в `7 (999) ...`. Значение начинается с цифры, поэтому `#ERROR! Синтаксическая ошибка` больше не возникает. Это исправление работает сразу после обновления `script.js`, даже если Apps Script ещё не переразвёрнут.

После этого заявки из квиза и короткой формы будут добавляться в лист **«Заявки»** со столбцами: дата, имя, телефон, площадь, бюджет, участок, срок заезда, тип формы, страница и UTM-метки.

Проверить приём можно, открыв адрес веб-приложения в браузере: должно появиться сообщение «Лендинг «Уральский каркас»: приём заявок активен».
